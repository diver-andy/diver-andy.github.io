# 潜水员 Andy · Diver Andy

AI 用代码写出来的 3D 潜水刺鱼网页游戏，手机 / 电脑浏览器点开就能玩。

- **第一人称写实版**：https://diver-andy.github.io/
- **3D 卡通版**：https://diver-andy.github.io/3d/
- **2D 像素版**（5 关 × 5 个 BOSS · 夜晚寿司消消乐 · 鱼枪装备商店）：https://diver-andy.github.io/2d/

玩法：左半屏拖动游泳 · 右半屏滑动看 · 按住射击键瞄准、松开发射 · 大鱼上钩狂点收线 · 右上角切换上午 / 黄昏 / 夜晚 · 回到船边「上船 · 收工」。
